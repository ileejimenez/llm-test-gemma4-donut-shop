# Golden Ring Donuts Mock Website

This is a mock, single-page website for a fictional local donut shop called **Golden Ring Donuts**, located in San Antonio, TX.

## Features
- **Responsive Design**: Works on desktop and mobile.
- **Full Navigation**: Smooth scrolling to different sections.
- **Hero Section**: Eye-catching visual entry.
- **Menu Section**: Displaying various donuts with prices.
- **About Section**: A little story about the shop.
- **Contact/Info Section**: Hours and location details.
- **Single File**: All CSS is contained within the HTML file for easy portability.

## Technologies Used
- HTML5
- CSS3
